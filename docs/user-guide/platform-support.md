# Compatibility

Platform and version requirements.

---

## Kotlin Version Support

Fakt supports Kotlin **2.2.0 through 2.4.10**, verified by CI on every change.

See the [Kotlin Compatibility Matrix](../compatibility.md) for the full list of tested versions and our backward compatibility philosophy.

---

## Gradle Version

- **Minimum**: Gradle 8.0
- **Recommended**: Gradle 8.10+

---

## JVM Version

- **Minimum**: JVM 11
- **Recommended**: JVM 21+

---

## Platform Support

Works on **all** Kotlin Multiplatform targets:

- ✅ JVM, Android
- ✅ iOS (arm64, x64, simulator)
- ✅ macOS, Linux, Windows
- ✅ JavaScript (IR), WebAssembly
- ✅ watchOS, tvOS

Single-platform projects (JVM-only, Android-only) are fully supported.
